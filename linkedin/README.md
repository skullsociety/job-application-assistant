# LinkedIn adapter

This folder contains the LinkedIn-specific Chrome extension, capture parser and matching adapter. It uses the suite-wide database, dashboard, resume folders and autofill profile documented in [the main guide](../README.md).

Load `linkedin/extension` as an unpacked Chrome extension after running the suite setup. Keep LinkedIn sign-in, application review and submission manual.

The original Playwright command-line and desktop interfaces remain in `job_assistant/`, `job_assistant.bat` and `Launch Linkedin Job Application Assistant.vbs` for users who still need them.
