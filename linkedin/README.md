# LinkedIn adapter

This folder contains the LinkedIn local service, capture parser and matching adapter. Its browser module now lives in `extension/sites/linkedin` and is loaded through the unified extension documented in [the main guide](../README.md).

Load only the root `extension/` folder in Chrome. Keep LinkedIn sign-in, application review and submission manual.

The original Playwright command-line and desktop interfaces remain in `job_assistant/`, `job_assistant.bat` and `Launch Linkedin Job Application Assistant.vbs` for users who still need them.
